# BYOU Collaboration Email Drafting — Rules

## Never include GitHub repository links in message templates
Never let a message draft (email replies, follow-ups, shipping confirmations, etc.) contain a link that points to a GitHub repository. This includes accidental auto-linking of text (e.g., "#1148" or other fragments turning into a hyperlink to a repo URL). If no real link is available for something, leave it as plain text and explicitly say a link is missing — never let a placeholder or stray link slip through, and never substitute a GitHub link for a missing tracking/shipping/content link.
